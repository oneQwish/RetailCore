# RetailCore

Проектная работа спринта 4: анализ требований и план поэтапной трансформации платформы RetailCore.

| Папка | Что внутри |
|---|---|
| `Task1` | Требования, карта стейкхолдеров, сценарии интервью, анализ интервью |
| `Task2` | Architecture Canvas, анализ артефактов, AS-IS диаграмма (`as-is.drawio`, `as-is.png`) |
| `Task3` | Описание трансформации и целевой архитектуры, TO-BE диаграмма (`to-be.drawio`, `to-be.png`) |
| `Task4` | Roadmap миграции и cutover-план |

Диаграммы открываются в draw.io, PNG лежат рядом для просмотра.
